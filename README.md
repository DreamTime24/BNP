
## Features

- **Background Video**: A looping background video is included for a dynamic effect.
- **Navigation Bar**: A responsive navigation bar for easy access to different pages.
- **Hero Section**: A glowing, welcoming section that introduces the party.
- **About Section**: Information about the party's founding and mission.
- **Vision Section**: Highlights the party's vision for the country.
- **Core Values**: A card-based display of the BNP's core values.
- **History**: A timeline describing the party's journey.
- **Media Section**: A video section showcasing BNP’s action and events.
- **Testimonials**: Quotes from supporters and party members.
- **Call to Action**: An invitation for users to join the movement.
- **Responsive Design**: The website is designed to be mobile-friendly and adaptive to different screen sizes.

## Technologies Used

- **HTML**: The structure of the website.
- **CSS**: The styling of the website.
- **JavaScript**: For interactive features like animations and scrolling effects.
- **AOS (Animate On Scroll)**: Used for adding scroll animations to the website.
- **Google Fonts**: For custom font usage (Poppins).
- **Video Background**: Embedded video as the background for the homepage.
